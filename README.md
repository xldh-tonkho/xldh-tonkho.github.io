# Tồn kho khả dụng

Giao diện app **Tồn kho khả dụng** của nhóm XLĐH (chạy trên GitHub Pages).

- Khả dụng = Hàng có sẵn − Tồn có đơn hàng.
- Dữ liệu tồn kho, tài khoản và đơn giữ hàng nằm trong Google Sheet; giao diện gọi API Google Apps Script.
- Đăng nhập bằng tài khoản được cấp trong trang `TaiKhoan` của file Google Sheet app.

File duy nhất cần sửa khi đổi giao diện: `index.html` (biến `API_URL` là địa chỉ API Apps Script).
